# asos-fashion-retail-analysis
Exploratory analysis of ASOS fashion retail data — brand performance, stock-out rates, and phantom revenue loss using Python, Pandas, and Seaborn.


## ASOS Fashion Retail Analysis

A data analysis project exploring product and brand-level insights from ASOS retail data.

### Key Analysis
- Brand cleaning and standardisation from raw scraped labels
- Stock-out rate calculation per product size listing
- Phantom (lost) revenue estimation from out-of-stock sizes
- Brand performance scatter analysis: price vs stockout rate vs lost revenue

### Tech Stack
Python · Pandas · Matplotlib · Seaborn

### Highlights
- Flags high-price, high-stockout brands as priority restocking targets
- Filters to statistically meaningful brands (min 10 products)
- Visual quadrant analysis with annotated brand labels
